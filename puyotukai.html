このシミュレータはぷよぷよクエストのぷよつかい大会におけるぬりかえをシミュレートし、素点が最大となるぬりかえを表示します.
1. 盤面空間の入力定義
 全て半角で入力. 以降の項目も同様.
 ・色情報: 1:赤, 2:青, 3:緑, 4:黄, 5:紫, 0:ハート で各セルを定義.
 ・プラス状態: プラスぷよを 1、通常状態を 0 と定義.
 ・ボーナスエリア: 対象セルを 1、非対象セルを 0 と定義.

2. ぬりかえ制約の設定
 ぬりかえ数を属性別に入力.
 ・塗 a: の最大ぬりかえ数
 ・塗 b: の最大ぬりかえ数

3. 演算時間の設定
 探索アルゴリズムの打ち切り時間(s)を入力. 単位は不要.
 （推奨値: 8s または 128s ）

4. 探索空間の定義
 探索深度 k ∈ ℕ0 を入力.
 (探索領域V = { (na, nb) | 塗a + 塗b - k <= na + nb <= 塗a + 塗b ; na <= 塗a, nb <= 塗b })

5. 演算の実行
 「探索開始」を押下. 計算処理がメインスレッドを占有するため、ブラウザから「応答なし」の警告が出る場合があるが、バックグラウンドでの収束計算は正常に進行中. 処理完了まで待機.

6. 解析結果の解釈と実行順序
 出力盤面上部に「なぞり消し座標」および「属性変換の優先順序」を表示.
 ・赤判定時: 赤からの変換が十分条件. 順序を誤るとぬりかえ時早期連結が発生し、なぞり消し前にオブジェクトが消滅する場合がある.
 ・青判定時: 青からの変換が必要条件. 順序を誤るとぬりかえ時早期連結が発生し、なぞり消し前にオブジェクトが消滅する.

補足. 予備1によるBE固定（拡張機能）
 「BE保」に 1 を入力して画像解析すると、盤面のぷよ色のみを最新に更新し、ボーナスエリアの配置は現在の設定のまま強制ロック（キープ）. 同じ編成でステージ周回する際に適宜使用.（通常時は 0 または空欄で自動解析.）

補足. 山登り法（「山登り」欄）
 0 または空欄なら従来のランダム探索. 1以上の数字を入れると山登り法になり、その回数だけ改善しなければ別の出発点へ移る（目安 300）. 山登り法では、探索後に Worker ごとの 5 秒ごとの最高点の推移が表示され、コピーもできる.

補足. 予備12の指示（保存・読込・自動読込）
 w_N: 現在の入力をスロットNへ保存.　r_N: スロットNを読み込む（予備12は書き換えない）.
 rr_N: 「探索開始」で監視を始め、2秒ごとにスロットNを見に行く. 盤面1行目（色行1）が前回と変わっていたら、r_N と同じ読み込みをして探索する. 探索が終わると「予備欄を表示」の横に「完了」ボタンが出て、その間は見に行かない. 「完了」を押すと監視を再開する.
