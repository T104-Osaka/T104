このシミュレータは、色を塗り替えてから、なぞり消しをして連鎖を起こす盤面を探し、最終ダメージが最大となる塗り替えとなぞり方を表示します.
1連鎖ごと・色ごとに 攻撃力 × 分離数 × {1+(同時消し数−4)×0.15×同時消し倍率} × (1+連鎖係数×連鎖倍率) を足し、最後に (1+ブースト加算) を掛けます.

1. 盤面の入力
 全て半角で入力. 以降の項目も同様.
 ・色情報: 1:赤, 2:青, 3:緑, 4:黄, 5:紫, 0:ハート で各セルを定義.
 ・プラス状態: プラスぷよを 1、通常状態を 0 と定義.
 ・ボーナスエリア（BE）: ボーナスエリアを 1、それ以外を 0 と定義. ここで消えた数が多いほど最終ダメージが上がる.

2. 塗り替える色
 ・塗る色1: （赤）. 塗1: 欄に、赤に塗り替える最大の個数（これ以下）を入力.
 ・塗る色2: （青）. 塗2: 欄に、青に塗り替える最大の個数（これ以下）を入力. なぞ=0 のときは使いません.
 ・先に塗る色: （なぞ=1以上のとき）. 「色1から」「色2から」を選ぶと、その色を先に塗っても途中で4つつながって消えない塗り方だけを探します. 「任意」のときは、どちらの順でもよく、結果の欄の末尾に、先に塗る色が●で表示されます（解析シムと同じ）.

3. なぞり消し
 ・なぞ: なぞり消しする最大の個数（小数は切り捨て）.
  0: なぞり消しをしません. 色1だけを塗り、塗った直後に4つ以上つながった塊が必ずできていることが条件です.
  1〜3: 色1・色2の2色を塗り、塗った後に4つ以上つながっていない（暴発しない）盤面だけを対象にします. なぞる集合は、縦横斜めに全部がつながっているもの（個数以下・枝分かれも可・最初の1個は2〜6行目）を全部試して、一番良いものを選びます.
  4以上: 全部は試せないので、塗り方となぞり方を山登りで一緒に探します.
 ・塗替% / なぞ%（4以上のとき）: 山登りで「塗り替えを1つ動かす」「なぞり方を動かす」割合（%）. 残りの割合が「両方を同時に動かす」割合になり、両方% 欄に自動で表示されます（初期値 55 / 35 / 10）.
 ・なぞったぷよは、同時消し数・分離数・ブーストの数に含めません. 連鎖の1連鎖目は、なぞった後の最初の消去です.

4. ダメージの設定
 ・赤攻〜紫攻: その色の攻撃力（整数. 空欄は 1000. ♡は攻撃しません）.
 ・同時×: 同時消し係数（基本 0.15）にかける倍率（空欄は 1）.
 ・連鎖×: 連鎖係数にかける倍率（空欄は 1. 倍率は 1＋連鎖係数×この値）.
 ・連鎖係数: 1連鎖目 0 / 2連鎖目 0.4 / 3連鎖目 0.7 / 4連鎖目 1.0 / 5連鎖目以降は 0.2 ずつ増加（上限なし. NEXT後の連鎖は「連鎖」欄で制限）.
 ・同時消し数は、その連鎖でその色が消えた数（プラスは2個分・♡は数えない）. 分離数は全色の合計の塊の数.
 ・ブースト加算: ボーナスエリアで消えた数（♡も含む・プラスは2個分）×4%、上限+200%. 最後までに消えた数の合計で決まり、全体に掛かります. 連鎖シミュレーションに出る色ごとのダメージ・各連鎖のダメージにも、この最終ブーストを掛けた値を表示します.

5. 演算時間と探索の方式
 ・実行時間: 探索の打ち切り時間(s).
 ・山登り: 空欄のときは 400 で山登り法（塗るマス・なぞるマスを1つずつ変えてダメージを上げ、その回数だけ改善しなければ別の出発点へ）. 0 を入れると完全ランダム探索（なぞ=4以上のときは、完全ランダムな塗り替えごとに、なぞり方を1000パターン山登り）.
 ・探索深度: 完全ランダムのとき、塗る個数を上限から何個まで減らして試すか.
 ・連鎖: NEXT落下後に数える連鎖の上限（入力値＋1回）.

6. 実行・保存
 「探索開始」を押下. 右下の予備12に w_N で保存、r_N で読込、rr_N で2秒ごとに自動読込（盤面1行目が変わったら読み込んで探索）. 保存先は他のシミュレータとは別.
